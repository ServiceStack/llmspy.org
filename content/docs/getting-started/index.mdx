## Using pip

The easiest way to install llms.py is using pip:

<ShellCommand>pip install llms-py</ShellCommand>

## Using Docker

### Pre-built Docker Images

Pull and run the latest image:

<ShellCommand>docker pull ghcr.io/servicestack/llms:latest</ShellCommand>

<ShellCommand>docker run -p 8000:8000 -e GROQ_API_KEY=$GROQ_API_KEY ghcr.io/servicestack/llms:latest</ShellCommand>

### Using docker compose (Recommended)

1. Download the docker-compose.yml file:

<ShellCommand>curl -O https://raw.githubusercontent.com/ServiceStack/llms/refs/heads/main/docker-compose.yml</ShellCommand>

2. Create a `.env` file with your API keys:

```bash
OPENROUTER_API_KEY=sk-or-...
GROQ_API_KEY=gsk_...
GOOGLE_FREE_API_KEY=AIza...
```

3. Create the host data directory before Docker mounts it:

<ShellCommand>mkdir -p ~/.llms</ShellCommand>

On Linux, add `PUID` and `PGID` to `.env` using the values from `id -u` and
`id -g` for the account that owns the data directory. For example:

```dotenv
PUID=1000
PGID=1000
```

Compose defaults to 1000:1000 when these variables are unset. The selected user
must be able to write to the directory. See [Docker permissions](/docs/deployment/docker#permission-issues-linux)
if the directory already exists with different ownership.

4. Start the service:

<ShellCommand>docker compose up -d</ShellCommand>

### Build from Source

If you've cloned the repository:

<ShellCommand>git clone https://github.com/ServiceStack/llms</ShellCommand>

<ShellCommand>cd llms</ShellCommand>

<ShellCommand>docker compose -f docker-compose.local.yml up -d --build</ShellCommand>

## Setup

[Setup environment variables](/docs/getting-started/quick-start#1-set-api-keys) for the providers you want to use.

## Updating

To update to the latest version:

<ShellCommand>pip install llms-py --upgrade</ShellCommand>

After upgrading, it's recommended to also upgrade any external extensions:

<ShellCommand>llms --update all</ShellCommand>

For Docker:

<ShellCommand>docker pull ghcr.io/servicestack/llms:latest</ShellCommand>

### Reset to latest configuration

New versions sometimes include changes to `llms.json` config which isn't automatically updated. 

Use the `--reset` option to reset the default configuration files back to its factory defaults. Available reset options (config, providers, all):

**config** - Reset [~/.llms/llms.json](https://github.com/ServiceStack/llms/blob/main/llms/llms.json) to default

```bash
llms --reset config
```

**providers** - Reset [~/.llms/providers.json](https://raw.githubusercontent.com/ServiceStack/llms/refs/heads/main/llms/providers.json) and [~/.llms/providers-extra.json](https://raw.githubusercontent.com/ServiceStack/llms/refs/heads/main/llms/providers-extra.json)

```bash
llms --reset providers
```
